# 《莉莉的衣橱冒险》故事型宣传片方案

## 一句话故事

城堡里的小公主莉莉发现衣橱中的漂亮裙子被淘气的影子小狐狸偷走，裙子被封印在衣橱世界的星光宝箱里。莉莉进入衣橱世界，通过推箱解谜点亮星光位置，逐章解锁裙子，最后让城堡重新恢复闪耀。

## 成片建议

- 时长：30—35秒
- 画幅：16:9，1280×720或1920×1080
- 风格：温暖、梦幻、儿童向的3D童话动画电影
- 豆包负责：城堡开场、偷衣服、进入衣橱世界、结尾动画
- 游戏负责：真实游戏界面、真实推箱操作、真实衣橱界面

关键原则：不要让豆包生成游戏界面、按钮、关卡数字或中文文字。生成模型很容易把UI和文字做错，游戏段必须使用当前游戏的真实录屏，再把动画段剪在前后。

## 统一角色锁定词

下面这段建议复制到每一个豆包提示词末尾，保持莉莉形象一致：

> 固定主角莉莉：东方童话小公主，幼龄可爱比例，栗棕色头发，高发髻，头顶一枚粉色蝴蝶结，大眼睛，圆脸，温柔坚定的表情。默认穿玫瑰粉色连衣裙，白色圆领和白色短袖，白袜，棕色小皮鞋。人物脸型、发型、蝴蝶结、身高比例和服装颜色在所有镜头中保持一致。温暖粉色、奶油色、金色的梦幻童话配色，精致3D动画电影质感，柔和体积光，细腻材质，干净构图，儿童友好，不恐怖。

统一负面词：

> 不要文字，不要字幕，不要水印，不要logo，不要UI，不要按钮，不要乱码，不要多余人物，不要恐怖元素，不要血腥，不要写实真人，不要改变主角发型和脸，不要多手指，不要畸形肢体，不要横竖画幅变化。

## 分镜与豆包提示词

### 镜头1｜城堡衣橱的秘密（0—4秒）

**作用：** 交代公主、城堡和漂亮衣橱，建立童话感。

**豆包提示词：**

> 16:9横屏，3D童话动画电影开场。夜晚的粉色童话城堡，月光穿过高大的拱形窗，镜头从城堡外缓慢推进到公主房间。房间中央是一座发着柔和金光的梦幻衣橱，衣橱里挂着蓝色、紫色、粉色、金色的漂亮礼服。莉莉站在衣橱前，惊喜地伸手触碰一件玫瑰粉色裙子，衣橱周围漂浮着细小星光。镜头缓慢推近衣橱和莉莉的脸，氛围温暖、神秘、期待。固定角色锁定词。统一负面词。

### 镜头2｜影子小狐狸偷走裙子（4—8秒）

**作用：** 给出冲突，说明为什么要冒险。

**豆包提示词：**

> 延续上一镜头的公主房间和衣橱。窗帘被一阵轻风吹动，一个淘气但不恐怖的紫黑色影子小狐狸从衣橱旁边探出头来，施展小小的魔法。衣橱里的漂亮裙子化成蓝、紫、粉、金色的发光丝带，被吸入一个旋转的星光门。莉莉惊讶地追上去，伸手却只抓住一颗掉落的金色星星。影子小狐狸带着裙子钻进衣橱深处，星光门逐渐缩小。镜头跟随发光丝带快速进入衣橱，产生轻快的冒险感。固定角色锁定词。统一负面词。

### 镜头3｜进入衣橱世界（8—12秒）

**作用：** 把现实动画自然接到游戏世界。

**豆包提示词：**

> 16:9横屏，镜头从旋转的衣橱内部穿过，进入一个巨大的梦幻衣橱世界。衣橱世界由五个不同区域组成：阳光玩具房、草莓茶会厅、秘密花园、月光阁楼、皇家衣帽间。莉莉从星光传送门中落地，面前出现奶油色棋盘、木箱和发光的星星位置，远处有一扇通往下一章的门。莉莉握紧金色星星，勇敢地向前走。镜头从莉莉背后环绕到正面，最后快速推近木箱和发光星星，准备切入真实游戏画面。固定角色锁定词。统一负面词。

### 镜头4｜切入真实游戏（12—21秒）

**不用豆包生成，使用当前游戏真实录屏。**

建议录制内容：

1. 首页点击“开始游戏”。
2. 第1关完整显示木箱、人物和发光星光位置。
3. 连续录制几次方向操作，让人物真实走动、木箱真实被推动。
4. 尽量录到一次木箱进入星光位置、星星变亮、通关提示出现。

剪辑方式：镜头3结束时用一颗金色星星做转场，接到真实游戏棋盘中的发光星星。保留游戏原本的按钮和关卡信息，不加豆包生成的UI。

### 镜头5｜衣橱解锁（21—26秒）

**游戏界面部分使用真实衣橱录屏；外部光效可以后期加。**

真实录制：打开衣橱，展示当前玫瑰晨礼裙，再展示解锁后的新裙子卡片。

后期效果：在已解锁裙子上加金色光圈和星星粒子，做一个轻微放大；锁定的裙子保持灰暗，突出“继续闯关才能解锁”。不要修改人物脸、头发和皮肤颜色，只变化衣服。

### 镜头6｜裙子回到城堡（26—31秒）

**豆包提示词：**

> 16:9横屏，延续莉莉和粉色城堡的统一角色与美术风格。莉莉站在城堡衣橱前，把一颗颗金色星星放入衣橱中央的星光锁。衣橱门缓缓打开，蓝色、紫色、粉色、金色的漂亮裙子重新回到衣架上，房间被温暖金光照亮。淘气的影子小狐狸从衣橱后面探出头，露出不好意思又可爱的表情，把最后一条裙子交还给莉莉。莉莉微笑着接过裙子，影子小狐狸变成一团友善的小星光。镜头环绕两人，最后停在闪耀的衣橱和莉莉身上。儿童友好、温暖、圆满结局。固定角色锁定词。统一负面词。

### 镜头7｜结尾宣传画面（31—35秒）

**豆包只生成无文字结尾动画，标题后期叠加。**

**豆包提示词：**

> 16:9横屏，梦幻童话动画电影结尾。莉莉穿着全新的闪耀礼服站在粉色城堡露台，身后是打开的巨大衣橱，五个章节的梦幻场景像星星一样漂浮在天空中，木箱、金色星星和柔和粒子围绕她旋转。莉莉向镜头伸出手，邀请观众进入衣橱世界。镜头慢慢拉远，城堡、衣橱和星光组成温暖的童话全景。画面中央留出干净空间，不能出现文字和水印。固定角色锁定词。统一负面词。

后期叠加文字：

> 莉莉的衣橱冒险
> 50关推箱解谜 · 解锁梦幻衣橱

## 剪辑节奏

| 时间 | 内容 | 来源 |
|---|---|---|
| 0—4秒 | 城堡、衣橱、莉莉 | 豆包动画 |
| 4—8秒 | 影子小狐狸偷走裙子 | 豆包动画 |
| 8—12秒 | 莉莉进入衣橱世界 | 豆包动画 |
| 12—21秒 | 第1关真实推箱操作 | 当前游戏录屏 |
| 21—26秒 | 真实衣橱、裙子解锁 | 当前游戏录屏+后期光效 |
| 26—31秒 | 裙子回到城堡 | 豆包动画 |
| 31—35秒 | 结尾标题和召唤 | 豆包动画+后期文字 |

## 豆包实际操作顺序

1. 先上传当前首页截图、当前人物截图、当前衣橱截图作为参考图。
2. 先用镜头1生成一张关键帧，确认莉莉脸型、发型、粉裙子正确。
3. 以镜头1关键帧作为后续镜头的角色参考，再分别生成镜头2、3、6、7。
4. 每个视频镜头控制在3—4秒，先生成短片，不要一次生成35秒长片。
5. 只把豆包生成的动画桥段放进剪映；游戏界面段使用当前游戏录屏。
6. 在剪映中加入音乐：开场音乐盒，偷衣服时轻快神秘音效，进入衣橱时星光上升音效，推箱时保留游戏推箱音效，解锁时加入清脆铃声。

## 需要避免的失败方式

- 不要让豆包直接生成带中文按钮、关卡数字、衣橱卡片文字的游戏截图。
- 不要让豆包重新设计莉莉的脸、发型和衣服，否则会出现人物不一致。
- 不要把动画里的木箱、星星位置当成真实关卡画面；两者只用于转场，真实玩法必须用游戏录屏。
- 不要用旧宣传片里的弃用背景和旧人物截图。
