# 《莉莉的衣橱冒险》正式版构建与项目交接

更新时间：2026-09-25

## 一、项目概况

- 游戏名称：莉莉的衣橱冒险
- 包名：`com.lilywardrobe.quest`
- 当前版本：`0.2.0`
- 游戏类型：离线单机、休闲益智、推箱子、换装
- 当前平台：Android 手机、Android PAD、Windows x64、H5
- 当前开发形态：Vite + React + TypeScript + Capacitor
- 当前开发者信息：魔杰工作室，136417505@qq.com

游戏核心玩法是：玩家控制小女孩在棋盘上移动，把箱子推到带有光亮提示的目标点，完成关卡后获得星星，并可在衣橱中查看和切换服装。

## 二、已经完成的内容

### 游戏功能

- 首页、开始游戏、关卡选择、衣橱入口已实现。

## 四、构建命令

在项目根目录执行。

### 1. 构建 H5

```powershell
npm run build:android:web
```

成功后检查 `dist-android/index.html` 是否存在，再将 `dist-android` 整体压缩为 H5 交付包。

### 2. 构建正式 APK

```powershell
npm run build:android:locked
```

该命令会：

1. 构建 H5 资源；
2. 同步 Capacitor Android 工程；
3. 使用本地 Gradle 构建 Release APK；
4. 使用发布证书签名；
5. 输出到 `releases/lilys-wardrobe-v0.1.2.apk`；
6. 验证 APK 签名。

如果命令提示签名证书或密码未配置，不要把未签名包提交给平台，应先配置本机环境变量，再重新构建。

### 3. 构建前检查

```powershell
npm run validate:levels
npm run test
```

`validate:levels` 负责关卡结构检查；`test` 还会执行构建和自动化测试。自动测试通过不等于已经完成真实手机上的 50 关人工试玩。

这些问题不能在没有实际设备复测的情况下宣称已经彻底解决：

3. 需要在 Chrome、Android 真机和 iPad 尺寸下分别检查棋盘、人物、箱子、目标点的中心点是否一致。
4. 需要确认通关目标点的光亮没有越界，也没有出现星星图片切边或残留测试文案。
5. 需要确认正式版首页不出现“测试版”“50 关解锁”“衣服解锁”等测试阶段文案。
6. 音乐和音效仍需要最终听感验收，尤其是宣传片与游戏内音乐不要误认为是同一条音轨。
7. 宣传片、16:9 宣传图、1:1 宣传图应单独检查尺寸、编码、大小和是否包含旧版画面。
8. 隐私政策页面目前只是项目内页面，尚未形成可提交给 TapTap 的 HTTPS 公网链接。
