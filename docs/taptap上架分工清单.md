## 需要你完成

### A. 确认运营主体

请先确定 TapTap 资料使用哪一种主体：个人、工作室或公司。

操作位置：TapTap 开发者中心 → 财务与管理 → 厂商设置 → 账号信息。

你只需要告诉我最终用于隐私政策的公开主体名称和对外联系邮箱。身份证号、身份证照片、营业执照等敏感材料不要发到聊天中，直接在 TapTap 后台上传。

### B. 准备 ICP 核准/备案

当前按“联网 + 无内购开放试玩”准备，需要 ICP 核准信息。若还没有：

1. 进入 TapTap 开发者中心 → 工单。
2. 选择游戏上架/资质或 APP 备案相关分类。
3. 说明：游戏为无内购的开放试玩版本，尚无版号，需要申请 TapTap 测试游戏备案辅助证明。
4. 按 TapTap 回复，在工信部 ICP/IP 地址/域名信息核准管理系统完成 APP 核准。
5. 拿到核准号和系统截图后，在开发者中心 → 商店 → 游戏资质 → ICP 核准上传。

如果已经有 ICP 核准号，准备核准号、系统截图和运营主体盖章/授权材料，直接在上述入口填写。

### C. 准备防沉迷/实名材料

TapTap 页面明确要求：提供 APK 测试或下载时，必须完善未成年人防沉迷系统并上传证明视频。没有版号也可以在 TapTap 开通“暂无版号”方案；这比直接申请游戏版号更适合当前先做试玩。

有两条路线：

- APK 可下载路线：接入 TapTap 实名认证/防沉迷能力，按要求做实名、未成年人时段限制和证明视频。
- 不改 APK 的试玩路线：咨询 TapPlay，由 TapPlay 在沙盒内提供防沉迷；代价是玩家不能直接下载 APK。

建议优先咨询 TapPlay 自带方案，或按 TapTap 工单确认当前 Capacitor 游戏如何接入。最终证明视频至少要展示：

- 无游客模式，必须实名后进入游戏
- 未成年人实名信息可以被正确识别
- 非规定时间未成年人无法游玩
- 周五、周六、周日和法定节假日 20:00–21:00 可以游玩

### D. 广告 SDK 接入前检查

如果第一版不接广告，建议先提交无广告版本，少一个联网和隐私合规变量；如果必须接广告，不能直接把生产广告位塞进包里，至少完成以下事项：

- 确定广告 SDK 厂商、SDK 版本、AppId 和广告位 ID，并使用测试广告位完成开发验证。
- 在用户同意游戏隐私政策后再初始化广告 SDK；拒绝同意时游戏仍应能进入并游玩，不能因广告加载失败卡住关卡。
- 在隐私政策中逐项披露广告 SDK 厂商、收集的信息、使用目的、共享方式、保存期限和第三方隐私政策链接。
- 只申请广告 SDK 实际需要的权限；检查 Android 广告标识符、设备信息、网络状态等采集项目是否与隐私政策一致。
- 确认广告展示位置不遮挡棋盘、方向键、通关按钮，不在用户误触时强制跳转外部页面。
- 上线前把测试广告位、调试日志和测试开关全部替换/关闭，并重新做拒绝隐私授权、断网、首次启动和升级安装测试。

广告接入后，APP 备案、隐私政策和防沉迷材料要按“联网游戏”重新向 TapTap 工单确认；网站隐私政策的 ICP 备案与 APP 备案不是同一件事。

操作位置：开发者中心 → 商店 → 游戏资质 → 未成年人防沉迷 → 编辑/上传证明视频。

### G. 办理官方游戏出版物号（ISBN/游戏版号）

这里的 ISBN 不是开发者在 TapTap 里自助申请的编号，而是网络游戏出版物号/游戏版号。国内移动游戏通常由具备网络游戏出版资质的出版单位作为申请主体，向省级出版管理部门提交，由省级部门审核后报国家新闻出版署。国家新闻出版署公布的办理时限为受理后约 80 个工作日，实际还取决于补正和排队情况。

官方入口和依据：

1. 国家新闻出版署“网络游戏出版物号核发”办事指南：<https://www.nppa.gov.cn/bsfw/xksx/cbfxl/wlcbfwspsx/202210/t20221013_600725.html>
2. 国家新闻出版署网络游戏申报材料填报说明：<https://www.nppa.gov.cn/bsfw/xksx/tbsm/201904/t20190419_5141.html>
3. 已批准游戏公示查询：<https://www.nppa.gov.cn/bsfw/jggs/yxspjg/>

实际办理顺序：

1. 先确认“魔杰工作室”是个人/个体工作室，还是有营业执照的公司。若只是个人品牌，不能自己充当有资质的出版单位，需要找国内有网络游戏出版资质的出版/发行合作方。
2. 准备软件著作权证书、最终游戏名称、运营主体、最终 APK、玩法说明、游戏截图/录屏、用户协议、隐私政策、未成年人保护和防沉迷材料。
3. 找出版/发行合作方做内容和材料初审。签订出版或独家授权链条时，游戏名称、著作权人、运营单位、出版单位必须能对应，后续 TapTap 上传的主体也要一致。
4. 由出版单位按省级出版管理部门要求提交申请书、移动游戏申请表、审查意见、签字盖章材料、电子材料和演示视频；不是个人直接在新闻出版署网站点一个按钮就能拿到编号。
5. 等审核通过，取得批准文件和出版物号。出版物号通常是类似 `978-7-...` 的编号，同时要保存批准文件/核发单扫描件。
6. 回到 TapTap：开发者中心 → 商店 → 资质与审核 → 游戏资质 → 编辑，上传官方游戏出版物号（ISBN）和批准文件 JPG/PNG 扫描件；保存后还要单独点击提交资质审核。
7. 资质通过后，在商店 → 当前版本 → “+” 创建未发布版本，Android 游戏状态才选择“正式上线”，上传正式签名 APK 并提交审核。

没有版号时，不要填写虚构编号，也不要把“软件著作权号”当成 ISBN。TapTap 当前规则下，无版号通常只能走“开放试玩/正式上线试玩版”，不能按正式商业发行版提交。

### H. HTTPS 隐私政策和备案边界

HTTPS 本身不等于 ICP 备案。TapTap 要的是一个真实可访问的 HTTPS 隐私政策链接，并要求链接内容与游戏内隐私政策一致、主体名称一致、页面内链接可打开；论坛帖子不能作为隐私政策地址。

你有三种选择：

1. 如果已有稳定的 HTTPS 官网，直接在该站点放 `/privacy.html`，无需另买域名。
2. 仅做短期测试，可使用稳定的 HTTPS 静态托管子域名；但正式审核时要确认大陆网络可访问、页面长期不失效。
3. 正式上架最稳妥：注册自己的域名，使用国内云静态托管/服务器，申请免费 SSL，并按服务商流程做 ICP 备案。无需购买实体服务器，但域名和中国大陆节点通常会涉及备案。

网站 ICP 备案、APP 备案、游戏版号是三件不同的事；不要因为要 HTTPS 就误以为三者可以互相替代。当前游戏代码没有广告 SDK、没有支付和统计 SDK，隐私页面应继续如实写明“本地存档、无广告、无第三方广告 SDK”；如果以后接广告，必须重新补充 SDK 收集信息和隐私链接。
