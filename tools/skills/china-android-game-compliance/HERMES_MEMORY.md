# 国内安卓游戏合规长期约定

当用户开发或上架面向中国大陆平台的安卓游戏时，主动检查并落实：适龄提示、首次启动隐私同意、实名认证与防沉迷 SDK、平台后台开通、真机测试以及正式签名构建。

关键原则：

- 隐私同意必须早于防沉迷、广告、统计、登录等 SDK 初始化；拒绝时退出或停止相关处理，并保留可再次访问的隐私政策入口。
- 防沉迷应在进入玩法前完成，失败、取消、断网、受限时段或平台要求退出时不能绕过。
- 适龄提示不能替代实名认证和防沉迷，年龄等级必须根据当前游戏及平台规则判断。
- 每个平台只用最新官方 SDK，核对实际接口、包名、游戏 ID、签名和后台开通状态；一个游戏的 ID、密钥或配置不得复用到另一个游戏。
- 代码接入、后台开通、真机验证、正式签名包是四项独立状态，报告时分别说明。
- 对手机版和 PAD 版分别构建验证；debug 包只能测试，正式上传使用发行签名。

好游快爆/3839：官方 SDK 文档为 https://open.3839.com/console/docs/#/service/sdk 。每次先核对最新版本。2026-04-15 的 OperateSDK 1.4.4.4 单机防沉迷模块为 hykb-common、hykb-login、hykb-anti、hykb-single；新版入口为 UnionFcmParam.Builder 与 UnionFcmSDK.init。游戏 ID 45613 只属于“莉莉的衣橱冒险”，不可用于其他游戏。
